# Hospitality-Booking-Insights-Dashboard
An interactive Power BI dashboard built using a hospitality dataset to analyze revenue, bookings, customer trends, and business performance using dynamic visuals, KPIs, slicers, and DAX measures.
## Dataset used
-<a href="https://github.com/lathifabhanulepakshi/Hospitality-Booking-Insights-Dashboard/blob/main/Hospitality_dataset.xlsm"> Hospitality Dataset</a>
## Project Overview
This project is an interactive Hospitality Booking Insights Dashboard developed using Microsoft Power BI.
The dashboard transforms raw hospitality data into actionable insights by analyzing revenue trends, booking performance, and service category contributions.
The objective of this project is to demonstrate strong skills in data cleaning, data modeling, DAX calculations, and business intelligence reporting.

## Business Problem
Hospitality businesses generate large volumes of booking and revenue data.
Without proper visualization and analysis, it becomes difficult to:
Monitor revenue performance
Identify top-performing categories
Track booking trends over time
Make data-driven decisions
This dashboard solves these challenges by providing an interactive analytics solution.
## Dashboard Features
KPI Cards (Total Revenue, Total Bookings, Performance Metrics)
Bar Chart – Category-wise Revenue Analysis
Line Chart – Revenue Trend Over Time
Pie/Donut Chart – Revenue Distribution
Slicers – Dynamic filtering by category/date
Interactive cross-filtering visuals
Custom DAX Measures

## Tools & Technologies Used
Power BI Desktop
DAX (Data Analysis Expressions)
Power Query Editor
Excel Dataset
Data Modeling & Relationships

## DAX Measures Implemented
Examples of measures used in this project:
Total Revenue = SUM(Hospitality[Revenue])
Total Bookings = COUNT(Hospitality[Booking_ID])
## Data Preparation Steps
Imported Excel dataset into Power BI
Cleaned and transformed data using Power Query
Handled missing values
## Key Insights Generated

Tracked monthly booking trends

Measured overall business performance
